# Возмещение расходов

Вымышленные сведения для демонстрации, не правила действующей компании.

Расходы согласуют до покупки. Для возмещения нужны чек и описание рабочей цели покупки. Документы передают в бухгалтерию. Расходы без чека рассматриваются отдельно: автоматическое возмещение не предусмотрено. Личные покупки не возмещаются.
