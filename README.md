# ИИ-помощник

[![Tests](https://github.com/ilya-baylov/knowledge-assistant/actions/workflows/tests.yml/badge.svg)](https://github.com/ilya-baylov/knowledge-assistant/actions/workflows/tests.yml)

Ответы по базе знаний компании в Telegram.

Регламенты лежат в документах, расписания — в таблицах, а за ответом сотрудник всё равно идёт к руководителю или в общий чат. Помощник позволяет спросить своими словами и получить ответ по материалам компании.

Проект работает как внутренний Telegram-бот с доступом для сотрудников.

[Открыть бота](https://t.me/SAXAP_ai_bot) · [Связаться с разработчиком](https://t.me/baylov93)

Доступ к рабочему боту выдаёт администратор.

## Использование

На 18 октября 2026 года доступ к боту есть у **60 сотрудников**. За последние 30 дней **24 сотрудника задали 94 вопроса**. Обращения администраторов в эту статистику не входят.

В рабочей базе знаний **157 документов**. В публичном репозитории вместо них лежат вымышленные документы для запуска примера.

## Как им пользуются

Сотрудник пишет вопрос или отправляет голосовое сообщение. Бот находит подходящие материалы и отвечает с учётом разговора. Если вопрос относится к конкретному филиалу, поиск учитывает это.

Например, можно спросить, как действовать при жалобе клиента или где найти нужную инструкцию. Затем уточнить детали следующим сообщением — повторять весь вопрос не нужно.

Если данных не хватает, бот просит уточнить вопрос или сообщает, что ответа в базе нет. Неразобранные вопросы попадают в список для администратора: по ним видно, чего не хватает в документах.

## Что умеет

- **Искать по смыслу и по словам.** Понимает свободную формулировку, но сохраняет поиск точных названий и терминов.
- **Учитывать филиал и контекст.** Разделяет материалы разных подразделений и обрабатывает уточнения в диалоге.
- **Принимать голосовые вопросы.** Переводит речь в текст и обрабатывает её как обычное сообщение.
- **Работать с документами и таблицами.** Читает PDF, Word, Excel и текстовые файлы; для сканов предусмотрено распознавание.
- **Собирать обратную связь.** Сотрудник может сообщить, что ответ неверный или неполный.

## Управление из Telegram

Администратор добавляет сотрудников по приглашениям, управляет ролями и лимитами. Там же можно загрузить документ, обновить поисковую базу, посмотреть вопросы без ответа и замечания к ответам.

При обновлении повторно обрабатываются изменённые материалы. Доступны статистика обращений, состояние индекса и напоминания о документах, которые пора проверить на актуальность.

## Как это устроено

Документы разбираются на фрагменты и попадают в поисковый индекс. Для вопроса объединяются два вида поиска: по смысловой близости и по точным словам. Найденные фрагменты передаются модели вместе с контекстом диалога.

Доступ проверяется до обработки вопроса. Пользователи, история разговоров, индекс и обратная связь хранятся в SQLite. Канал Telegram отделён от поиска и подготовки ответа.

## Несколько решений в проекте

**Два вида поиска.** Сотрудник может описать задачу своими словами или назвать точный термин из документа. Векторный поиск и FTS5 объединены, чтобы обрабатывать оба случая.

**Учёт филиала.** В базе могут лежать одноимённые документы разных подразделений. Указанный в вопросе филиал влияет на подбор материалов; данные разных подразделений не должны смешиваться в ответе.

**Вопросы без ответа.** Они сохраняются для администратора. Это помогает находить пробелы в документах и дополнять базу по реальным обращениям.

**Проверки без рабочей базы.** Тесты создают временные документы и подменяют обращения к моделям. Их можно запускать без ключей API и данных компании; автоматическая проверка настроена в GitHub Actions.

## Технологии

| Часть | Технологии |
| --- | --- |
| Telegram-бот | Python, aiogram |
| Подготовка ответов и распознавание речи | OpenAI API |
| Поиск | Эмбеддинги, NumPy, SQLite FTS5, русский стемминг |
| Данные | SQLite, SQLAlchemy, aiosqlite |
| Документы | pypdf, python-docx, openpyxl |
| Фоновые задачи | APScheduler |
| Проверки | pytest, pytest-asyncio, наборы вопросов для оценки поиска |

Основной промпт не задаёт отрасль компании. Дополнительные правила для сервисного бизнеса можно включить через `generation.domain_rules_template: domains/service_business.j2` в `config/bot.yaml`. В коде остаются специализированные обработчики расписаний и предложений; для другой отрасли их поведение нужно проверить на своей базе.

Модель ответов и модель эмбеддингов настраиваются отдельно. Повторная индексация использует кэш эмбеддингов, чтобы не обрабатывать одинаковые фрагменты заново.

## Запуск

Нужен Python 3.12, токен Telegram-бота и ключ API для моделей.

```bash
git clone https://github.com/ilya-baylov/knowledge-assistant.git
cd knowledge-assistant
python -m venv .venv
```

Активируйте окружение: `source .venv/bin/activate` в Linux/macOS или `.venv\Scripts\Activate.ps1` в PowerShell. Затем установите зависимости:

```bash
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env`. Заполните `TELEGRAM_BOT_TOKEN`, `OPENAI_API_KEY` и свой Telegram ID в `ADMIN_IDS`. Название компании и поведение помощника задаются в `config/bot.yaml`.

В `knowledge/demo/` лежат вымышленные документы для первого запуска. Перед загрузкой своих материалов удалите их, чтобы примеры не попадали в ответы.

```bash
python -m app.cli ingest
python -m app.channels.telegram.bot
```

Доступ закрыт по умолчанию. Администратор может пригласить сотрудника командой `/invite` или заранее указать его ID в `STAFF_IDS`.

Для Docker: сначала выполните `docker compose build`, затем `docker compose run --rm bot python -m app.cli ingest` и `docker compose up -d`.
