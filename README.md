# ИИ-помощник

Ответы по базе знаний компании в Telegram.

Регламенты лежат в документах, расписания — в таблицах, а за ответом сотрудник всё равно идёт к руководителю или в общий чат. Помощник позволяет спросить своими словами и получить ответ по материалам компании.

Проект работает как внутренний Telegram-бот с доступом для сотрудников.

## Как им пользуются

Сотрудник пишет вопрос или отправляет голосовое сообщение. Бот находит подходящие материалы и отвечает с учётом разговора. Если вопрос относится к конкретному филиалу, поиск учитывает это.

Например, можно спросить, как действовать при жалобе клиента или где найти нужную инструкцию. Затем уточнить детали следующим сообщением — повторять весь вопрос не нужно.

Если данных не хватает, бот просит уточнить вопрос или сообщает, что ответа в базе нет. Неразобранные вопросы попадают в список для администратора: по ним видно, чего не хватает в документах.

## Что умеет

- **Искать по смыслу и по словам.** Понимает свободную формулировку, но сохраняет поиск точных названий и терминов.
- **Учитывать филиал и контекст.** Разделяет материалы разных подразделений и обрабатывает уточнения в диалоге.
- **Принимать голосовые вопросы.** Переводит речь в текст и обрабатывает её как обычное сообщение.
- **Работать с документами и таблицами.** Читает PDF, Word, Excel и текстовые файлы; для сканов предусмотрено распознавание.
- **Собирать обратную связь.** Сотрудник может сообщить, что ответ неверный или неполный.

## Управление из Telegram

Администратор добавляет сотрудников по приглашениям, управляет ролями и лимитами. Там же можно загрузить документ, обновить поисковую базу, посмотреть вопросы без ответа и замечания к ответам.

При обновлении повторно обрабатываются изменённые материалы. Доступны статистика обращений, состояние индекса и напоминания о документах, которые пора проверить на актуальность.

## Как это устроено

Документы разбираются на фрагменты и попадают в поисковый индекс. Для вопроса объединяются два вида поиска: по смысловой близости и по точным словам. Найденные фрагменты передаются модели вместе с контекстом диалога.

Доступ проверяется до обработки вопроса. Пользователи, история разговоров, индекс и обратная связь хранятся в SQLite. Канал Telegram отделён от поиска и подготовки ответа.

## Технологии

| Часть | Технологии |
| --- | --- |
| Telegram-бот | Python, aiogram |
| Подготовка ответов и распознавание речи | OpenAI API |
| Поиск | Эмбеддинги, NumPy, SQLite FTS5, русский стемминг |
| Данные | SQLite, SQLAlchemy, aiosqlite |
| Документы | pypdf, python-docx, openpyxl |
| Фоновые задачи | APScheduler |
| Проверки | pytest, pytest-asyncio, наборы вопросов для оценки поиска |

Модель ответов и модель эмбеддингов настраиваются отдельно. Повторная индексация использует кэш эмбеддингов, чтобы не обрабатывать одинаковые фрагменты заново.
