# Проверка поиска и ответов

[На главную](../README.md)

В `eval/questions.yaml` — 22 вопроса по шести вымышленным документам из `knowledge/demo/`. Темы: первые рабочие шаги, заявки, расходы, командировки и офисы двух городов. Есть вопросы, на которые в этой базе нет ответа.

## Запуск

Используйте отдельную базу данных и только демодокументы. Не смешивайте этот набор с рабочими материалами: вопросы и ожидаемые источники относятся к вымышленной компании.

После настройки `.env` и индексации демобазы:

```bash
python -m app.cli eval --output data/search-report.json
python -m app.cli eval --answers --output data/answer-report.json
```

Первый режим проверяет поиск ожидаемого источника среди первых пяти результатов. Второй также формирует ответ и проверяет наличие заданных ключевых фрагментов или отказ при недостатке данных. Режимы используют настроенный API эмбеддингов; `--answers` дополнительно обращается к модели ответов.

В JSON сохраняются результаты каждого вопроса, оценки поиска, тексты ответов при включённом режиме и время обработки. Ошибка хотя бы одного случая даёт ненулевой код завершения.

## Что означают результаты

Это набор для проверки изменений на конкретных примерах. Совпадение ключевых фрагментов не гарантирует смысловую правильность всего ответа. Оно также не проверяет все виды галлюцинаций, устойчивость к prompt injection, многотуровые диалоги и качество на документах другой компании.

Автоматические тесты отдельно проверяют отказ без источников, фильтрацию слабых совпадений и обработку неподтверждённых чисел. В них модель подменена; их результат не выдаётся за оценку реальной LLM.
