# Устройство помощника

[На главную](../README.md)

## От документов до поисковой базы

Загрузчики извлекают текст из документов и таблиц. Вместе с содержимым сохраняются метаданные: раздел, филиал, название и срок актуальности, если он задан. Для сканов предусмотрен отдельный этап распознавания.

Текст разбивается на фрагменты. Для каждого строится векторное представление; параллельно обновляется полнотекстовый индекс SQLite FTS5. Русский стемминг помогает находить слова в разных формах.

Изменения файлов и метаданных учитываются при следующей индексации. Эмбеддинги одинаковых фрагментов берутся из кэша. Обновлённый индекс подхватывается без перезапуска бота.

## Путь вопроса

1. Проверяются доступ сотрудника и лимит обращений.
2. Голосовое сообщение при необходимости переводится в текст.
3. Учитываются история разговора и указанный в вопросе филиал.
4. Поиск подбирает материалы по смысловой близости и точным совпадениям. Для отдельных типов данных, например расписаний, предусмотрена дополнительная обработка таблиц.
5. Модель получает найденные фрагменты и готовит ответ. При недостатке данных предусмотрены уточнение вопроса и сообщение об отсутствии информации.
6. История, вопросы без ответа и замечания сотрудников сохраняются для дальнейшей работы.

## Основные части

| Модуль | Задача |
| --- | --- |
| Канал Telegram | Сообщения, голосовые вопросы, команды и панели администратора |
| Сервис вопросов | Проверка доступа, лимиты и выполнение запроса |
| Подготовка базы | Загрузчики, метаданные, разбиение на фрагменты и индексация |
| Поиск | Векторная и полнотекстовая выдача, фильтрация по разделам |
| Подготовка ответа | Контекст диалога, вызов модели и обработка результата |
| Хранилище | Сотрудники, документы, фрагменты, история и обратная связь |

## Обслуживание

Панель администратора показывает состояние базы, статистику вопросов и задачи, требующие внимания. Обновление индекса сопровождается прогрессом и итогом обработки. Вопросы без ответа можно разобрать и отметить решёнными.

В проекте есть автоматические тесты обработки документов, поиска, диалогов и доступа. Отдельные наборы вопросов используются для проверки качества поиска и ответов после изменений.

Ключи провайдеров и рабочие документы хранятся на сервере. При обработке вопроса выбранные фрагменты передаются настроенному провайдеру модели.
